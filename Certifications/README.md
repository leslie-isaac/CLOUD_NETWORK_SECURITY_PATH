# Certifications

This folder contains all the certifications I have earned during my journey to becoming a Cloud & Network Engineer.  

## Purpose
- Showcase officially earned certifications  
- Serve as a professional record for recruiters or portfolio viewers  
- Track progress over time  

## Organization
- Each certification has its own subfolder named clearly, e.g.:  
  - AWS-Cloud-Practitioner  
  - AWS-Solutions-Architect  
  - Terraform-Associate  
  - Security-Plus  

- Inside each certification folder, store:  
  - The certificate file (PDF, PNG, or JPG)  
  - Optional: exam completion date, credential ID, or verification link
